# codex-persistent-runner

Python/SQLite single-worker queue with durable completion receipts, checkpoints, bounded recovery and systemd containment. Configuration is explicit; no existing service is installed or modified by these sources.

Experimental sources maintained by Syldegil. [Français](README.fr.md).
